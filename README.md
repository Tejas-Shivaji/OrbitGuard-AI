# OrbitGuard-AI

An interactive satellite tracking and orbital intelligence platform built using Python and Streamlit.

## Features

- Interactive 3D Earth visualization
- Satellite tracking using TLE data
- Orbital propagation using SGP4
- Satellite selection and filtering
- Conjunction screening
- Indian satellite asset monitoring
- Mission intelligence and priority analysis
- TLE data health checks
- Screening audit support

## Technology Stack

- Python
- Streamlit
- Plotly
- NumPy
- Pandas
- SGP4

## Project Structure

- app/ - Streamlit application
- src/data/ - Satellite data handling
- src/orbit/ - Orbital calculations
- src/risk/ - Risk and intelligence analysis
- tests/ - Automated tests
- data/ - Supporting assets

## Installation

1. Clone the repository.
2. Create a Python virtual environment.
3. Install dependencies using pip install -r requirements.txt.
4. Run python -m streamlit run app/main.py.

## Testing

Run python -m pytest.
